PEKERJAAN YANG HARUS DITUNTASKAN
1. Periksa `git status --short`, proses Composer yang mungkin masih berjalan, dan berkas scripts, docs, dist, serta `.runtime/vendor-prod`. Hindari membaca berkas berulang kali dan jangan menelusuri vendor, node_modules, atau build.
2. Selesaikan ketidakcocokan composer.json dan composer.lock. Siapkan vendor produksi yang lengkap tanpa paket development. Jangan masukkan .env, akun uji, kredensial lokal, .runtime, node_modules, log, atau token unduhan.
3. Jalankan migrasi dan seeder hanya pada database kosong khusus `ukpr_export`; jangan mengosongkan atau mengubah database proyek lain. Hasilkan `dist/ukpr.sql` berisi konten awal tanpa akun admin atau rahasia.
4. Uji proses pembuatan paket dari awal hingga akhir. Hasilkan ZIP dengan aplikasi di luar public_html (contoh `ukpr_profile_app`) serta folder publik yang dapat ditentukan namanya (contoh `public_html/ukpr`). Pastikan path subdomain bisa dikonfigurasi, file upload tetap privat tanpa symlink, PHP dapat menemukan aplikasi, dan URL serta aset berfungsi dari document root publik.
5. Ekstrak ZIP ke folder staging baru yang tidak menimpa berkas apa pun. Periksa manifest dan aset produksi, vendor/autoload.php, SQL, .env.example, .htaccess, PHP lint, path deploy, dan isi ZIP. Pastikan contoh konfigurasi memiliki `APP_DEBUG=false`, `APP_KEY` dan `SETUP_TOKEN` kosong serta dibuat lokal, tanpa akun admin produksi. Buat checksum ZIP.
6. Jika melakukan perubahan, jalankan kembali test yang relevan dan buka website lokal untuk memastikan masih berfungsi. Jangan klaim situs sudah diuji pada cPanel; hosting sebenarnya belum tersedia.
7. Berikan lokasi ZIP, SQL, checksum, URL serta akun uji lokal yang diverifikasi, hasil test, dan langkah awal instalasi. Password akun uji lokal boleh diberitahukan kepada saya, tetapi jangan dimasukkan ke ZIP.
8. Hapus atau sanitasi script yang mengandung token pada URL aset sebelum membuat paket. Jangan berhenti untuk meminta persetujuan tambahan; saya sudah meminta pekerjaan diteruskan sampai siap upload. Jelaskan batasan hosting yang benar-benar masih ada.
